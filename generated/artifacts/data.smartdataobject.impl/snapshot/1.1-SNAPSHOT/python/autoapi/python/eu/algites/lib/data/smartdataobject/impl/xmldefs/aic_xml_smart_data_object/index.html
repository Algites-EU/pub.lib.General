Mutable XML Schema object with namespace-aware, order-tolerant parsing.

Generated types can declare __xml_field_types__ mapping field names to concrete nested SmartDataObject classes, plus __xml_repeated_fields__ for fields with maxOccurs greater than one. Both mappings are inherited. Unknown attributes/elements, duplicate non-repeating QNames, unexpected mixed content and unsupported nested types are rejected rather than lost.

classmethod from_xml(aXml: str, aNestedTypes: collections.abc.Mapping[str, type] | None = None)¶

Create a concrete typed object from XML without enforcing child order.

XML element and attribute identities use expanded QNames. Repeated siblings preserve document order within their own field. Typed nested objects must be declared on the class or supplied through aNestedTypes. The standard SmartDataObject validation runs after population.

Parameters:

  • aXml – XML document containing exactly one document element

  • aNestedTypes – optional field-to-concrete-class overrides for this level

Returns:

the populated generated SmartDataObject subtype

Raises:

  • ValueError – for unknown, duplicated, or structurally invalid content

  • TypeError – if no safe conversion exists for a field
