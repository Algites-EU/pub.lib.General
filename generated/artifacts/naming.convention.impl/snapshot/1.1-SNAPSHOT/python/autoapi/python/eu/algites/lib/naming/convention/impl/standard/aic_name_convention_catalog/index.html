class python.eu.algites.lib.naming.convention.impl.standard.aic_name_convention_catalog.AIcNameConventionCatalog(config: Mapping[str, Any])¶

YAML-driven, language-independent name composition engine.

Java-style (?<name>…) captures in YAML are translated to Python’s (?P<name>…). Only file_name_stem + file_name_suffix is used to identify a file’s profile.

classmethod load_resource(filename: str) → AIcNameConventionCatalog¶

Read the resource from the importable Python package or its Modustro resource bundle.

This uses Python package-resource lookup, never the source-repository layout. Modustro publishes config resources under this artifact’s isolated resource namespace. A local Python environment may also expose the config source root directly as a namespace package on sys.path.

classmethod load_many(sources) → AIcNameConventionCatalog¶

Load an ordered set of file/resource catalogs without permitting conflicting IDs.

An identifier defined identically in multiple files is shared. Distinct definitions of one identifier are always an error; file order never grants precedence.
